# Validate Password

Projeto desenvolvido em **Java** utilizando **Spring Boot**.

## 🚀 Tecnologias Utilizadas

- **Java**: Linguagem de programação utilizada no projeto.
- **Spring Boot**: Framework para construção da API.

## ✨ Funcionalidades

- **Validação de Senha Segura**: Implementação das regras exigidas no desafio.
- **API REST**: Endpoint para validação de senhas.
